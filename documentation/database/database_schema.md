\# Relational Database Schema Specification  
\*\*Author:\*\* Martin Robinson (System Architect)    
\*\*Target Engine:\*\* PostgreSQL Baseline Configuration  

\#\# Purpose  
Defines the relational database schema supporting:  
\- Authentication  
\- Role-Based Access Control (RBAC)  
\- Telemetry Storage  
\- Alert Management  
\- Audit Logging

for the OxyGuard platform.

\#\# Data Relationships Blueprint

\`\`\`text  
wards  
  │  
  └──── devices  
            │  
            ├──── telemetry\_logs  
            │  
            └──── alerts   
                    │ (resolved\_by)  
                    ▼  
roles ─── role\_permissions ─── permissions  
  │  
  └──── users  
            │  
            └──── audit\_logs  
\`\`\`

\---

\#\# Core Tables & Column Definitions

\#\#\# 1\. Table: roles  
\* \`role\_id\` (Primary Key \[PK\], Serial)  
\* \`role\_name\` (VARCHAR(50), Unique, Not Null) \- e.g., 'Admin', 'Nurse Manager', 'Nurse'

\#\#\# 2\. Table: permissions  
\* \`permission\_id\` (Primary Key \[PK\], Serial)  
\* \`permission\_name\` (VARCHAR(100), Unique, Not Null) \- e.g., 'resolve\_alert', 'view\_logs'

\#\#\# 3\. Table: role\_permissions  
\* \`role\_id\` (Foreign Key \[FK\] references roles.role\_id, Not Null)  
\* \`permission\_id\` (Foreign Key \[FK\] references permissions.permission\_id, Not Null)  
\* \*Composite PK:\* (\`role\_id\`, \`permission\_id\`)

\#\#\# 4\. Table: users  
\* \`user\_id\` (PK, Serial)  
\* \`username\` (VARCHAR(100), Unique, Not Null)  
\* \`email\` (VARCHAR(150), Unique, Not Null)  
\* \`email\_verified\` (BOOLEAN, Default: False, Not Null)  
\* \`password\_hash\` (VARCHAR(255), Not Null)  
\* \`role\_id\` (FK references roles.role\_id, Not Null)  
\* \`created\_at\` (TIMESTAMP, Default: CURRENT\_TIMESTAMP, Not Null)

\#\#\# 5\. Table: wards  
\* \`ward\_id\` (PK, VARCHAR(50)) \- e.g., 'ICU-A'  
\* \`ward\_name\` (VARCHAR(100), Not Null)  
\* \`location\` (VARCHAR(100))

\#\#\# 6\. Table: devices  
\* \`device\_id\` (PK, VARCHAR(50)) \- e.g., 'ESP32-WARD1-ICU'  
\* \`ward\_id\` (FK references wards.ward\_id, Not Null)  
\* \`created\_at\` (TIMESTAMP, Default: CURRENT\_TIMESTAMP, Not Null)

\#\#\# 7\. Table: telemetry\_logs  
\* \`log\_id\` (PK, BigSerial)  
\* \`device\_id\` (FK references devices.device\_id, Not Null)  
\* \`ward\_id\` (FK references wards.ward\_id, Not Null) \- Denormalized for historical ward tracking  
\* \`flow\_rate\` (NUMERIC(5,2), Not Null) \- Matches telemetry contract limits  
\* \`operational\_status\` (VARCHAR(20), Not Null) \- Enum: normal, warning, critical, hardware\_fault  
\* \`device\_timestamp\` (TIMESTAMP, Not Null) \- Generated by ESP32 edge node  
\* \`received\_at\` (TIMESTAMP, Default: CURRENT\_TIMESTAMP, Not Null) \- Server runtime ingestion stamp
\* \`cylinder\_capacity\` (NUMERIC(12,2), Nullable) \- Cylinder capacity in litres for replacement events
\* \`consumed\_volume\` (NUMERIC(12,2), Nullable) \- Oxygen consumed before replacement
\* \`cylinder\_status\` (VARCHAR(20), Nullable) \- Enum when supplied: IN\_USE, REPLACED
\* \`breathing\_variance\` (NUMERIC(12,6), Nullable) \- Patient breathing waveform variance used for ghost flow detection
\* \`emr\_status\` (VARCHAR(50), Nullable) \- Current bed or patient assignment status from the EMR

\#\#\# 8\. Table: alerts  
\* \`alert\_id\` (PK, Serial)  
\* \`device\_id\` (FK references devices.device\_id, Not Null)  
\* \`alert\_type\` (VARCHAR(50), Not Null) \- e.g., 'low\_pressure', 'leak', 'hardware\_fault'  
\* \`severity\` (VARCHAR(20), Not Null) \- Canonical enum: high, medium, low, critical
\* \`is\_resolved\` (BOOLEAN, Default: False, Not Null)  
\* \`resolved\_by\` (FK references users.user\_id, Nullable) \- Tracks validating user  
\* \`resolved\_at\` (TIMESTAMP, Nullable) \- Identifies timestamp of resolution event  
\* \`created\_at\` (TIMESTAMP, Default: CURRENT\_TIMESTAMP, Not Null)
\* \`remaining\_volume\` (NUMERIC(12,2), Nullable) \- Unused oxygen for residual gas alerts
\* \`unused\_percentage\` (NUMERIC(7,6), Nullable) \- Fraction of cylinder capacity left unused
\* \`estimated\_oxygen\_waste\` (NUMERIC(12,2), Nullable) \- Estimated wasted oxygen in litres
\* \`estimated\_financial\_loss\` (NUMERIC(14,2), Nullable) \- Waste multiplied by configured cost per litre
\* \`potential\_savings\` (NUMERIC(14,2), Nullable) \- Recoverable value when replacement procedures are corrected
\* \`recommended\_action\` (VARCHAR(255), Nullable)

\#\#\# 9\. Table: audit\_logs  
\* \`audit\_id\` (PK, Serial)  
\* \`user\_id\` (FK references users.user\_id, Not Null)  
\* \`action\` (VARCHAR(100), Not Null) \- e.g., 'Resolve Alert'  
\* \`target\` (VARCHAR(100), Not Null) \- e.g., 'Alert \#45'  
\* \`performed\_at\` (TIMESTAMP, Default: CURRENT\_TIMESTAMP, Not Null)
