# OxyGuard

OxyGuard is a Management Information System prototype for monitoring oxygen usage, leakage, hardware faults, alerts, and operational reporting.

## Project Objective

Demonstrate a complete data-to-decision pipeline:

Sensor → ESP32 → Backend → PostgreSQL → Dashboard → Alerts → Audit Logs

## Week 1 Architecture Package

The architecture package includes:

- System Architecture Diagram
- Context Diagram
- Level 1 Data Flow Diagram
- Telemetry Data Contract
- Database Schema Specification
- Entity Relationship Diagram
- API Specification
- RBAC Matrix
